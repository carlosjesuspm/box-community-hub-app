# BoxCommunity App
**Goal**: The all-in-one platform for managing your CrossFit box and tracking athlete performance.

## **Mainly Features**
*For athletes:*
* Class Management
    - Manual and automatic class booking.
    - Waiting list.
    - View capacity in real time.

* Training and WODs
    - WOD calendar.
    - Scheduled training sessions.
    - Automatic training volumen adjustements.

* Personal tracking
    -  Personal records (PRs).
    -  Historic PRs.

* Integratiosn
    - Smartwatches.
    - Strava.
    - Apple.

*For coaches:*

* Scheduling
    - WODs and events creation.
    - Information and tips for training.

* Box Management
    - Administrator.
    - Attendance monitoring.
    - Personal chats with users.
    - Payments.

## **Software Design**
This application uses a hexagonal architecture and vertical slicing allowing each funcionality will be autonomous. I chose this design because it helps to reduce innecesary code and simplify project management.
